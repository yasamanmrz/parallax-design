🏠 Home Design

A modern and elegant Home Design website built with HTML, Tailwind CSS, CSS animations, and Swiper.js.

The project focuses on creating a visually immersive interior design experience with warm neutral colors, smooth transitions, interactive sliders, and a fully responsive layout.

✨ Features

🎨 Modern interior design UI

🖼️ Interactive Swiper slider

✨ Smooth CSS animations

🎨 Warm beige, cream, and brown color palette

⚡ Built with Tailwind CSS

📐 Responsive design for different screen sizes
